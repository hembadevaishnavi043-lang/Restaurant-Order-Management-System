# Restaurant-Order-Management-System

About the Project: 

The Restaurant Order Management System is a simple Python project used to manage food orders in a restaurant. It uses Stack and Queue data structures implemented using Linked Lists.

Purpose:

The purpose of this project is to understand how Stack and Queue operations work using Linked Lists. It helps manage restaurant orders by adding new orders, preparing them in the correct sequence, and maintaining a history of prepared orders.

Features:

1.Add new food orders.
2.Prepare the next order.
3.Display pending orders.
4.Display order history.
5.Remove the latest history entry.
6.Exit the program.

Data Structures Used:
1. Queue: Stores food orders and processes them in the order they are received (FIFO).
2. Stack: Stores prepared order history, with the latest entry appearing first (LIFO).
3. Linked List: Stores data dynamically using nodes.

Technology Used:

Programming Language: Python
Concepts: Stack, Queue, and Linked List
